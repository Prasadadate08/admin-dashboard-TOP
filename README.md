# admin-dashboard-TOP

An admin dashboard layout built with HTML and CSS. The goal was to practice CSS Grid by building the whole page out of nested grids.

## Features

- Three-part page layout (sidebar, header, main content) built with CSS Grid.
- Sidebar with a branding section and two navigation groups, each icon paired with a label.
- Header with a search bar, notification and user info, plus a greeting row with action buttons (New, Upload, Share).
- Icons from Material Design Icons, and the Roboto font from Google Fonts.

## Technologies

- HTML
- CSS (Grid)

## Notes

This project is part of The Odin Project curriculum. Most of the layout is grids nested inside grids, as the project suggested. It was good practice for `grid`,`grid tracks`, `nested grids`,`fr` units,`SVG` format and spanning rows and columns.


### Known issues

- It's not a pixel-perfect match to the design example.
- The layout isn't fully responsive and can break on narrow screens.
- I might want to revisit this after more grid practice.
